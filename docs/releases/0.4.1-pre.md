# Diablo Reincarnated 0.4.1-pre

24 October 2026.

The existing HD renderer accepts optional larger canvases for original-named
sprite sheets. A versioned `.png.layout` file supplies source density and fixed
anchors. This gives extended limbs and moving shadows room without resizing the
character or changing Classic movement, attack timing, damage, range or tiles.
Sheets without metadata keep their previous placement and fallback behavior.

The Paladin knee test uses the larger canvas, a fixed tile-ground anchor and
southeast sunlight with a full moving northwest shadow. Existing shortened walk
and idle sheets use the same anchor/light direction, preventing directional or
action-dependent shifts. These proprietary local assets are not in Git or the
public build sources. The executable's product/file version is 0.4.1-pre;
upstream save/network versions are unchanged.

Validation: synthetic compositor tests cover legacy and expanded sheets, source
decoding, malformed metadata fallback, 1x/2x anchors, viewport clipping, Classic
buffer preservation, palette/lighting/blending and foreground coverage. The real
expanded knee atlas also passed the streaming decoder/anchor test. All custom
body and shadow poses passed canvas-bound checks. The 4,853-frame HD gameplay
replay exited successfully with the same final reference-save outcome (58.81 s,
82.5 fps including the existing capture/presentation work). This does not establish
a complete playthrough or visual coverage of every class/animation.

The isolated 2,700-frame full-game town/UI replay loaded the expanded 20-frame
idle sheet at 3072 x 7680 retained pixels, exercised HD/Classic switching, menus,
panels and zoom, and exited successfully (20.08 s, 134.5 fps). Normal and zoomed
GPU captures were visually inspected. This replay has no final reference-save
comparison. The new knee's gameplay feel still needs a live attack check.
