# Diablo Reincarnated 0.4.6-pre

29 October 2026.

The existing modified engine now renders the complete Warrior class from cropped,
packed **4x BC7 GPU sprites**. All 255 sheets (light/medium/heavy armor and equipment
combinations) are preloaded into VRAM before gameplay. The approved 85 custom light
Warrior sheets preserve their motions, frame counts and logical anchors; other
Warrior art remains the original NN artwork at 4x sampling. No model, simulation,
attack timing, stride, save format or original PNG pixels are changed.

The 760 packed pages contain 2,525,855,744 bytes (**2.352 GiB**), plus
a shared 64 MiB exact RGB-to-palette lookup, render targets, control data and driver
overhead. The class has **zero retained CPU RGBA player-sheet bytes** on this path.
This replaces the previous 4.47 GiB 2x CPU player cache while retaining higher-detail
4x textures. Upload staging and control textures are reused. Palette lookup work
is warmed during loading and level changes. Class pages survive F10 and equipment
changes; returning to the menu releases them.

Screen smoothing is disabled with nearest-pixel scaling. F11 now reports GPU sheet
count, BC7 page allocation and draw activity. Those allocation counters are not
GPU timestamps or total driver VRAM usage. Terrain/monster/legacy composition
still uses the existing CPU path; this release does not claim a complete GPU world
renderer. Compatible PNG fallback remains for unavailable packs/backends and the
virtual gamepad overlay path.

Validation passed all six provider/renderer/statistics/coverage tests, the PNG and
CPU compositor integration tests, and real-GPU synthetic readback checks for exact
palette lookup, lighting/TRN, native 2x viewport, ordered actors, transparency,
opaque occlusion, cursor restoration and resource release. Every compiled page
was decoded offline, all 255 source PNG hashes and the existing anchor table were
verified, and all frame records were checked. Across 85 sampled custom frames,
worst visible RGB RMSE was 2.4358 and alpha RMSE 2.2606 on the 0–255 scale.

Two fresh 4,853-frame gameplay replays match the original reference save. A
1,000-tick normal-speed UI replay covers F11 on/off, HD/Classic, menu, inventory,
character panel, zoom and cursor; private captures were reviewed. All test audio
uses 50% master gain without changing normal preferences. All three replays retain
255 GPU sheets and 760 uploads, with no later player-page uploads or player PNG
decodes. No other class is preloaded.

Reference-run class preparation took 4.733 and 4.546 seconds; drive/cache conditions
affect these local observations. The largest sampled process physical working set
was 752,992,256 bytes (about 0.70 GiB); largest private commit was 3,724,554,240 bytes
(about 3.47 GiB). These differ: private commit includes reservations/backing and is
not a measure of physically resident RAM. Scene/driver costs vary with gameplay;
these replays are validation, not a controlled normal-play FPS benchmark.
