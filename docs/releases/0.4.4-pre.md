# Diablo Reincarnated 0.4.4-pre

28 October 2026.

Loading a save or new game now prepares all installed named PNG sheets for the
selected character's sprite class before gameplay begins. This includes every
armor tier and weapon/shield combination. The current Warrior has 255 sheets,
using 4.47 GiB of decoded RAM at the renderer's existing retained 2x density.
Other classes are not preloaded; multiplayer peers retain on-demand loading.

Character sheets are protected from normal LRU eviction and survive F10,
display resets and level changes. They are released on leaving the game.
Other scene assets retain an evictable cache with at least 512 MiB of headroom
when the pinned class exceeds the ordinary target. The existing memory-warning
policy remains; no source PNG size/resolution cap is added.

The original game data supplies animation grids and widths. MPQ reads stay on
the loading thread, followed by up to four independent PNG decoders. Cache,
metadata lookup and diagnostic output are synchronized. The existing loading
bar covers both native loading and character preparation. PNG pixels, anchors,
models, animation timing, simulation, saves and `HD/layouts.csv` are unchanged.
CSV data remains cached until process exit as in 0.4.3-pre.

Tests cover provider enumeration and precedence, eight concurrent metadata
readers with exactly one CSV read, pinned image reuse across resets, class
replacement, release/reload, and the existing PNG/compositor regressions.
The build installer requires replay proof matching the exact binary hash,
verifies existing PNG/CSV hashes, backs up the prior executable and manifests,
and restores them if final verification fails.

Hidden replay fixtures disable focus-loss autopause only in their isolated
configuration, so desktop focus changes during the longer loading screen cannot
pause recorded gameplay. Normal user preferences are never changed.

Final validation passed: all four provider/renderer tests, the PNG/compositor
integration test, and both executable-install/rollback tests. Two independent
4,853-frame gameplay replays match the original reference save. A separate
2,700-frame menu, inventory and HD/Classic replay exits 0.

Each final run loaded all 255 Warrior sheets, skipped zero, retained exactly
4,794,935,808 bytes, and performed zero further player PNG decodes after the
preload—even after F10 and level changes. No Rogue/Sorcerer PNGs were decoded.
Observed preload times were 46.123, 46.218 and 46.301 seconds with four workers.
These are local measurements; filesystem cache/drive conditions affect loading.
The largest sampled process-private commit was about 5.15 GiB. This includes
more than the player buffers and remains below the 8 GiB warning target.
