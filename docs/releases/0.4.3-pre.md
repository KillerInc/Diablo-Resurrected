# Diablo Reincarnated 0.4.3-pre

28 October 2026.

Sprite alignment metadata is consolidated in `HD/layouts.csv`. Its two columns
are `path` (relative to HD) and `layout` (existing density/anchor or numeric image
layout text). All 85 installed custom entries retain their exact values. The
runtime no longer reads individual `.layout` files.

The table is parsed once per used asset provider and remains resident until
process exit. F10 image reloads and texture/sheet eviction do not evict it.
Restart after editing the CSV. Image/provider precedence is preserved, with no
cross-provider metadata inheritance. Invalid CSV is diagnosed once and uses
existing default alignment; malformed density/anchors keep the renderer's
existing fallback. PNG size diagnostics, memory targets, gameplay and saves are
unchanged.

The offline collector and installer preserve exact metadata and executable
backups, verify PNG hashes, and roll back on failure. The active warrior install
workflow now updates the consolidated table instead of adding game sidecars.
Artwork, private lookup data and game saves are excluded from Git.

Validation covers quoted CSV paths, UTF-8 BOM/CRLF, case-insensitive lookup,
duplicates, invalid paths/quoting, provider isolation, one table read despite
repeated lookups, residency after source changes/removal, and fresh-process
reload. Synthetic migration tests cover metadata conversion, unchanged PNGs,
exact backups and restoration after a post-removal verification failure.

Completed validation: four provider/renderer tests, the PNG/compositor integration
test and four migration tests pass. The exact final game executable completed
4,853 gameplay frames in 60.47 seconds (80.2 fps), matching the reference save.
A separate 2,700-frame HD/Classic/menu replay exited 0. Each process reported
`HD_LAYOUT_CSV: loaded rows=85 cache=process-lifetime` exactly once, using a
private test pack containing no individual `.layout` files.
