# Diablo Reincarnated 0.4.5-pre

28 October 2026.

F11 now toggles an in-game performance overlay. Active gameplay also appends
once-per-reporting-interval metrics to `performance.csv` beside the configuration.
The Windows default is `%APPDATA%/KillerInc/Diablo Reincarnated/performance.csv`.
See [metric definitions](../PERFORMANCE.md) for timing boundaries and log details.

The monitor reports frame average/p95/max and >33.33/>50 ms counts; CPU-side
wall times for world drawing, HD composition and presentation; process-private
RAM; decoded sheet-buffer RAM and pinned count; and cache activity/load elapsed
time. Presentation includes waiting. These are not GPU timestamps or measured
VRAM usage. Loading/inactivity are excluded; F10 resets the reporting window.
Fixed storage avoids per-frame sample allocation. Overlay text and log writes
update once per reporting interval; the overlay starts hidden. F10 behavior,
selected-class preload/pinning, gameplay, art, animation and alignment are preserved.

Validation passed all five provider/renderer/statistics tests, the real PNG and
compositor integration checks, synthetic CSV/suspension checks, two monitor-proof
validator tests and two install/rollback tests. Two fresh 4,853-frame gameplay
replays match the original reference save with monitoring and F11 enabled.
A separate 3,000-tick normal-speed replay checks F11 on/off, HD/Classic, menu,
inventory, character panel and zoom. Private GPU captures were visually reviewed
in both rendering modes, including the pause menu; no artwork/captures/saves are
included in Git. The initial UI test fixture sent F11 too early; the corrected
fixture sends it after gameplay starts and holds each phase long enough for metrics.

Each final replay preloaded all 255 Warrior sheets, skipped zero and retained
4,794,935,808 pinned bytes. No player PNG was decoded again after preload and
no other player class was preloaded. CSV validation checked 249 rows across the
three replays, including both render modes. On-demand monster/missile loads remain
visible in the cache metrics; this release measures those costs without changing
their caching policy. Capture-enabled and timedemo measurements are not normal-play
benchmark claims.
