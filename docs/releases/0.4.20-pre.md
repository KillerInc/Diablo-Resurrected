# 0.4.20-pre: authored town NPC sheets

Approved town NPC replacements can use their own BC7 silhouette in the normal
HD renderer. A row in the existing cached `HD/layouts.csv` opts in explicitly:

```
towners/example/example.png,D1R_AUTHORED_SHEET_V1 4 48 96
```

The fields retain the existing density and logical anchor meanings. The marker
is accepted only for towners. Unmarked world art retains native index and
occupancy textures; Classic rendering is unchanged. The earlier private
`D1R_TEST_AUTHORED_TOWNERS` environment switch is no longer used.

The compiled sheet must still match the native direction and frame counts.
The native animation selects every frame, including pauses and reversed
sequences. Effects must be baked into those same frames; no second animation
clock or PNG runtime loading is introduced.

Private approved artwork for Griswold, Cain and Adria is supplied locally.
It includes southeast shadows and registered feet. Artwork, models, previews,
compiled texture pages and game saves are not included in Git.

Validation covers explicit versus unmarked silhouettes, rejection of wrong
frame counts, layout parsing, GPU lighting/occlusion and bounded real-pack
uploads. A separate muted town replay checks the supplied sheets in game.

Validated for this build:

- Synthetic GPU draw/readback and explicit authored-layout selection passed.
- Sheet parsing, offline PNG diagnostics and PNG-free runtime fallback passed.
- All 1,387 compiled records uploaded through the runtime loader: 3,061 pages,
  9,742,966,784 BC7 bytes, with bounded residency and no PNG decoding.
- The isolated muted town replay exited successfully and traced authored draws
  for all three approved replacements, with native frame counts retained.
- Release and debug executables report `0.4.20-pre`; the installed game archive
  matches both builds and needs no replacement.

The final three replacement textures were revalidated after matching the
warrior shadow settings (70% opacity, 2-pixel softening at 4x). Approved body
brightness and saturation are unchanged.
