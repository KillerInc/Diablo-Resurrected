# Diablo Reincarnated 0.4.0-pre

23 October 2026. Development build based on `073e2cc12d67cf5d09d9d114f2e7d78b7fd65493`.

## Changes

- Original-named player, monster and missile sheets follow the exact CL2/CEL animation asset selected by the existing engine, including player equipment and armor. Direction/frame provenance survives copied and translated sprites.
- The existing indexed game buffer, animation timing, visibility, world draw order, walking offsets and foreground coverage are preserved. Sheet colors follow palette translations, lighting and sprite blending while retaining truecolor smoothing residuals.
- Huge PNG sheets stream through a bounded system-memory cache. The cache defaults to 1 GiB and can be configured with `D1R_SHEET_CACHE_MB` (128–4096 MiB). Original sheet files stay untouched.
- The in-game version and Windows file/product version are now **0.4.0-pre**. Upstream numeric save/network versions remain unchanged.
- Windows CI builds and runs the new sheet-rendering regression target and checks executable version resources. Packages contain no user-supplied sheets or original game artwork.
- Added the project working agreement: GitHub records completed source/tests/docs; local source is a build/test workspace. User-supplied sheets stay outside version control.
