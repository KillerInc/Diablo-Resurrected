# Diablo Reincarnated 0.4.2-pre

27 October 2026.

The existing HD PNG loader replaces arbitrary size rejection with warning-only
diagnostics. PNGs can exceed the former 128 MiB decoded entry limit, 256 MiB
compressed loose-file limit and 65536-pixel source-axis limit. The loader still
validates the sheet grid, supported density, anchors, PNG format and allocation
arithmetic. Real memory exhaustion can still prevent loading.

The sprite cache now targets 4 GiB of system RAM, with an 8 GiB Windows process
private-commit warning target. Older cached sheets are evicted as needed; an
individual sheet larger than the cache target is admitted. Neither target is a
VRAM allocation or hard whole-game memory cap. Decode staging peaks are sampled
before the temporary buffer is freed.

Warnings append to `hd-sprite-loader.log` beside the configuration file and also
enter the application log. They include the source, sizes, warning target and
cumulative flags at 75%, 90% and 100%, with `action=continue`. Settings and exact
flag meanings are documented in [HD sprite sheets](../HD_SPRITE_SHEETS.md).
The SDL3 log callback's severity labels have also been corrected.

Regression coverage includes a real streamed PNG above 128 MiB retained, a PNG
65544 pixels wide with an anchor beyond 65536, a synthetic loose PNG resource
above 256 MiB, admission of a sheet exceeding the cache target, warning-file
output, warning thresholds and SDL3 severity labels. Existing malformed-sheet,
palette, compositor and Classic-preservation checks remain in place.

The executable display and Windows product/file versions are 0.4.2-pre. Save,
network and gameplay simulation versions are unchanged. Installed graphics,
models and saves are not part of the source changes or Git artifacts.

Validation completed: all four renderer/provider tests and the PNG/compositor
integration test pass. The exact final executable completed the 4,853-frame HD
gameplay replay with the same reference-save outcome in 57.61 seconds (84.2 fps).
Temporary 1 MiB per-sheet and 64 MiB process-warning targets forced diagnostics
during this private test; the installed defaults remain 128/8192 MiB. Warning
messages were followed by successful HD sheet loads and were also verified in
the dedicated file. This is replay/test coverage, not a complete playthrough or
an assertion that arbitrarily large files can fit available physical memory.
